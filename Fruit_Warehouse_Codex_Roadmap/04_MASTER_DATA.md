# Phase 04 — Master Data CRUD

## Goal
Build one-page AJAX CRUD for:
- Shops
- Categories
- Fruits
- Units
- Users if not already implemented

## UX
Each CRUD page:
- search
- filters
- server-side pagination
- Add modal
- Edit modal
- Delete confirmation
- status toggle
- AJAX submit
- inline validation
- toast/success message
- table refresh without full page reload

## Fruit fields
name, code, category, default unit, status, sort order.

## Shop fields
name, code, address, phone, email, status, delivery sequence.

## Requirement
Do not create separate create/edit pages unless there is a strong reason.
